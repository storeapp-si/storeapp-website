Privacy notice

This notice describes the current static directory experience. It must be updated if analytics, advertising, accounts or other data collection is added.

Search and filters

Search and category filters run in the browser. A shared search term may appear in the URL and browser history. Do not include sensitive personal information in search terms or links.

Tool links lead to other providers; their privacy policies and data practices apply.

Submissions

The site does not itself store tool submissions. The suggestion form opens a GitHub issue draft for the visitor to review and submit; GitHub terms apply. Public issues should not contain confidential information.

Changes

Review this notice if hosting, analytics, affiliate, advertising, contact or account services are introduced. This notice is informational, not legal advice.

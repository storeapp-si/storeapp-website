AI tools for architecture: feasibility, planning and visualisation

Autodesk Forma, TestFit and Veras address different phases of architectural work. Selecting one by a generic 'best AI' label misses the core distinction: site analysis, rapid feasibility and visual exploration are separate jobs.

Editorial method: This is a task-based decision guide, not a controlled benchmark or universal ranking. Product capabilities, access and pricing can change. Confirm current details with each vendor and test on your own representative workflow.

The short answer

Autodesk Forma

Evaluate for early-stage site analysis, environmental context and planning workflows where project context and connected design data matter.

TestFit

Evaluate for rapid real-estate feasibility and option studies, especially when testing building layouts, unit mix, parking and site yield.

Veras

Evaluate for AI-assisted visualisation and design exploration from an existing model or image; it is not a substitute for code-compliant design documentation.

Compare by project stage

Site and context

Use the same site boundary and constraints. Check how each workflow handles setbacks, access, orientation, surrounding context and missing data.

Feasibility and yield

Record assumptions for zoning, parking, unit sizes, circulation and cost. Compare editable outputs and the time required to produce a defensible option.

Visual exploration

Use the same model view and prompt brief. Check design consistency, material interpretation, geometry preservation and how easily a result can be revised.

A fair evaluation

  • Choose a real but non-confidential pilot site and document all assumptions before running the tools.
  • Ask whether outputs can be exported into the team's existing BIM/CAD workflow and which file formats or integrations are supported.
  • Check regional availability, licensing, collaboration, data residency and whether generated outputs can be used commercially.
  • Have architects and relevant planning professionals validate dimensions, regulations, structure, fire safety and accessibility.

Important limitation

  • Generative visualisations and automated feasibility outputs are exploratory aids. They do not establish planning permission, code compliance, structural safety or constructability. Final decisions require qualified professional review.
